1. CELERY AI TASK (products/tasks.py)
─────────────────────────────────────
   generate_ai_description_task(product_id, extra_specs="")
     • Runs exclusively inside Celery worker (Rule 3 — non-blocking)
     • Uses `from google import genai` → `genai.Client(api_key=...)`
     • Loads product image via Pillow, sends multimodal prompt to gemini-2.5-flash
     • Generates structured markdown:
       - ## Overview (2-3 sentence value proposition)
       - ## Physical Condition Assessment (visual inspection)
       - ## Technical Highlights & Specifications (bulleted specs)
     • Saves generated text → Product.description
     • Saves metadata → Product.ai_metadata (model, status, timestamp, char_count)
     • Retries up to 3 times on transient failures
     • Returns success payload: { product_id, status, description }

2. API ENDPOINTS
────────────────
   POST   /api/products/create/
     → Multipart form data (title, category, condition, image)
     → Creates Product record, returns full serialized product

   POST   /api/products/<uuid>/generate-description/
     → Dispatches Celery task, returns { task_id, status: "PENDING" }

   GET    /api/tasks/<task_id>/status/
     → Polls Celery AsyncResult, returns { task_id, status, result? }
     → Status values: PENDING → STARTED → SUCCESS / FAILURE

   PATCH  /api/products/<uuid>/
     → Partial update — seller edits AI-generated or manual description

   POST   /api/products/<uuid>/publish-auction/
     → Validates: starting_bid, bid_increment, reserve_price, start_time, end_time
     → Creates Auction record: LIVE if start_time ≤ now, else SCHEDULED
     → Returns { message, auction_id, status }

3. SERIALIZERS (products/serializers.py)

4. SELLER LISTING UI (templates/products/create_listing.html)
─────────────────────────────────────────────────────────────
   Three-step wizard with dark-mode glassmorphism design:

   Step 1 — Product Info:
     • Drag-and-drop image upload with live preview
     • Title input, category dropdown (11 categories), condition card selector
     • Optional "Additional Specs" field for AI context
     • "Create Listing" button → POST /api/products/create/

   Step 2 — AI Description:
     • "✨ Auto-Generate with AI" button (purple gradient)
     • Dispatches Celery task → polls /api/tasks/<id>/status/ every 2s
     • Spinner + status text during generation
     • Auto-populates <textarea> with fade-in animation on SUCCESS

   Step 3 — Auction Settings:
     • Starting Bid, Bid Increment, Reserve Price (৳ currency)
     • Start Time, End Time (datetime-local pickers)
     • Info banner: "If start time ≤ now → LIVE, else → SCHEDULED"

     • Green checkmark animation

     • Toast notifications for success/error feedback
